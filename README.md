# leave-management-system
A leave management system with role-based authentication for users, managers, and HR. Employees request leaves, managers approve/reject, and HR oversees records. Features secure login, leave tracking, and reporting, ensuring efficient workflow and compliance.
### External Repositories
- **PHPMailer**: Facilitates email functionality. Repository: [github.com/PHPMailer/PHPMailer](https://github.com/PHPMailer/PHPMailer). Integrated for updating password.
## Installation
1. Clone the repository: `git clone https://github.com/allanocodes/leave-management-system.git`
2. Install dependencies: `composer install`
